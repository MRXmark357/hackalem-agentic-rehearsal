# HackAlem AI — Трек: Агентные системы (Репетиция)

Репозиторий содержит решения двух отборочных задач репетиционного этапа.

---

## 1. Классификатор обращений (task1_classifier)

Скрипт разбирает входящие сообщения из файла messages.txt, определяет категорию (справка / жалоба / другое) и формирует черновик ответа на русском языке.

### Команда запуска:
python task1_classifier/classifier.py

### Результат работы:
* [1] Обращение: «Как получить справку о месте учёбы?» -> справка
* [2] Обращение: «В столовой очередь, еда холодная.» -> жалоба
* [3] Обращение: «Хочу записаться на консультацию завтра.» -> другое
* [4] Обращение: «Пропал Wi-Fi в корпусе В.» -> жалоба
* [5] Обращение: «Где парковка для гостей?» -> справка

---

## 2. Фильтр алертов (task2_filter)

Скрипт считывает список событий из events.json, фильтрует события уровня critical и выводит итоговую статистику.

### Команда запуска:
python task2_filter/filter_alerts.py
